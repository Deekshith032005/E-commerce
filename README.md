## How to Run the Project

### Requirements

* Java JDK 21
* Apache Tomcat 10.1
* MySQL
* Eclipse IDE (or any Java IDE that supports Dynamic Web Projects)

### Steps

1. **Clone the repository**

```bash
git clone <your-repository-link>
```

2. **Open the project in Eclipse**

   * Import the project as an existing Eclipse project.
   * Make sure Java 21 and Tomcat 10.1 are configured.

3. **Set up MySQL**

   * Install and start MySQL.
   * Create a database named:

```sql
CREATE DATABASE automart;
```

* Configure the MySQL username and password in `DBConnector.java`.

4. **Add the project to Tomcat**

   * Add the `automarts` project to Apache Tomcat 10.1.
   * Start the Tomcat server.

5. **Run the application**

   * Open your browser and visit:

```text
http://localhost:8080/automarts/
```
